# r02.01 Lead Capture To D1

This update starts the real lead-capture pipeline.

## What It Adds

- Public quote form submits to `/api/public/leads` when deployed.
- Honeypot spam field on the public form.
- Basic validation and allowed dropdown checks.
- Short-term anti-spam/rate-limit event table.
- New admin API routes under `/api/admin/*`.
- Admin task list in the admin UI.
- New quote requests create an admin follow-up task.
- Rule-based Quote Assist is generated and stored against the lead.

## Migration

Apply this migration in Cloudflare D1:

```text
migrations/0004_lead_capture_quote_assist.sql
```

Apply it after:

```text
0001_initial.sql
0002_seed_demo.sql
0003_job_followups.sql
```

## New API Routes

```text
POST  /api/public/leads
GET   /api/admin/leads
POST  /api/admin/leads
PATCH /api/admin/leads/:id
POST  /api/admin/leads/:id/notes
GET   /api/admin/tasks
POST  /api/admin/tasks
PATCH /api/admin/tasks/:id
```

## Security Note

This update creates the new public/admin route structure, but the older prototype `/api/*` routes still exist.

Before using real customer data:

- protect `/admin/*`
- protect all sensitive APIs
- either protect legacy `/api/*` or migrate/remove legacy routes before relying only on `/api/admin/*`

Use junk/test data until that hardening pass is complete.
