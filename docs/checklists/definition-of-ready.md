# Definition of Ready

A milestone must satisfy the Definition of Ready before AG begins implementation.

## Scope
- [ ] Milestone approved.
- [ ] In-scope items defined.
- [ ] Out-of-scope items listed.

## Product
- [ ] Business workflow agreed.
- [ ] UI changes approved (or explicitly none).
- [ ] Existing UI preservation confirmed.

## Technical
- [ ] Relevant documentation reviewed.
- [ ] Database impact identified.
- [ ] Migration requirement confirmed.
- [ ] API boundaries defined.
- [ ] Data relationships understood.

## Workflow
- [ ] Branch name agreed.
- [ ] Testing approach defined.
- [ ] Success criteria defined.
- [ ] Documentation impact expectations defined.

## Dependencies
- [ ] No conflicting feature branch exists.
- [ ] Required upstream milestone(s) are complete.
